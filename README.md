# Projet systèmes exploitations 2025

## Pour compiler:

**Full:**  
```
make
```  
OU  
```
gcc -Wall -Wextra -o erraid erraid.c task_runner.c
```

**Effacer tous les fichiers compilés:**  
```
make distclean
```

---


## Lancer erraid:

**Dossier /tmp/$USER/erraid :**  
```
./erraid
```

**Chemin tasks custom:**  
```
./erraid -r <chemin>
```
